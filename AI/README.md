# 🤖 AI Developer Resources

This directory contains resources specifically designed for **AI Coding Agents** to understand and generate code for the **NexHDL HDL** library.

## ⚠️ Work in Progress
Please note that these documents are a **work in progress**. NexHDL is under active development, and its internal APIs, hardware primitives, and backend integration patterns may evolve. 

## 📂 Contents
- **[nexhdl_reference.md](./nexhdl_reference.md)**: A dense technical reference and "Golden Standard" template for AI agents. This is the primary document an agent should read to produce syntactically and idiomatically correct hardware modules.

## 🎯 Purpose
The goal of these resources is to bridge the gap between human-readable documentation and the strict requirements of LLMs for code generation. By providing clear rules on:
- Hardware vs. Python logic distinction.
- Bit-level layout conventions (Endianness).
- Explicit width management.
- Parameter validation.

We ensure that AI agents can contribute robust, verifiable hardware components to the NexHDL ecosystem.
